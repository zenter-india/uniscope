# Product documentation

Uniscope helps prospective medical students discover universities through verified peer perspectives.

## Vision

Connect applicants with verified current students and alumni for anonymous, trustworthy insights about medical schools and programs.

## Core personas (future sprints)

| Persona | Goal |
| ------- | ---- |
| Prospective student | Research universities, ask questions, read reviews |
| Current student / alumni | Share experiences anonymously (verified) |
| Admin | Moderate content, manage verification, platform health |

## Product principles

1. **Trust through verification** — mentors are verified; identity can remain anonymous in discussions.
2. **Student-first UX** — mobile-first discovery and engagement.
3. **Safety and moderation** — admin tooling and policies (future).
4. **Incremental delivery** — ship thin vertical slices per sprint.
