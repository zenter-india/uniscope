# Sprints

Sprint folders capture goals, scope, retrospectives, and deliverables per iteration.

## Index

| Sprint | Focus | Folder |
| ------ | ----- | ------ |
| Sprint 0 | Monorepo foundation, tooling, docs | [sprint-0/](sprint-0/) |

## Sprint folder template

Each sprint directory should include:

```
sprint-N/
├── README.md       # Goals, scope, team
├── backlog.md      # Prioritized items
├── deliverables.md # What shipped
└── retrospective.md
```
